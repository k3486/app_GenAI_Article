## 興味のあるテーマ
1. 開発ツール・エージェント: Claude Code などの AI コーディングツール、AI エージェント、MCP、ワークフローの設計
2. 新モデル・性能比較: 新しいモデルの発表、ベンチマークや実利用での比較、料金の動向
3. 業務での活用事例: 企業の導入事例、業務を効率化する具体的なノウハウ
4. 規制・安全性・業界動向: 法規制、AI の安全性、資金調達・買収などのビジネスの動き
5. 有効な活用方法: ワークフローの構成やプロンプトの指示方法。公式の記事・ドキュメント

## 好む記事の特徴
- 手順・構成・プロンプト・設定が具体的で、条件が変わっても再現・転用できるもの
- 一次情報（公式ブログ・論文）や、数字・検証に裏づけられたもの
- 新しい情報や、業界への影響が大きいもの
- 論文でも、実務や事業への示唆が読み取れるもの

## 好まない記事
- 製品の宣伝だけのもの、出典のない推測、見出し程度の紹介、すでに知られている内容の繰り返し
