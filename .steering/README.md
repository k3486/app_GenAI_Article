# .steering — 作業履歴と中断・再開用の記録

## ルール
- 作業を始めたら `YYYYMMDD-<作業名>/` を作り、下の3ファイルを置く
- タスクが終わるたびに `tasklist.md` をチェック。中断する前に「次にやること」「中断メモ」を更新
- 作業が終わったら `history.md` に1行追記（追記のみ）し、`docs/` を最新の仕様に更新
- Claude は作業開始時に `history.md` と最新の `tasklist.md` を読んで続きから再開する

## 見本
### requirements.md
```
# <作業名>
## 目的
## やること / やらないこと
## 完了条件
```
### design.md
```
# 設計
## 方針
## 変更するファイル
## 決めたこと（理由つき）
```
### tasklist.md
```
# タスク
- [ ] ...
- [x] ...

## 次にやること
## 中断メモ（どこまで進んだか・気になっている点）
```
